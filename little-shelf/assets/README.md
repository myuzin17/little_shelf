# 에셋(선택)

이 폴더가 비어 있어도 앱은 Pillow로 직접 그린 기본 이미지로 동작합니다.
예쁜 일러스트가 생기면 아래 이름으로 PNG만 넣으면 자동으로 사용됩니다.

## containers/ — 용기 (480×480 투명 PNG)
- `basic_pot.png`, `round_pot.png`, `striped_pot.png`, `glass_vase.png`, `ribbon_vase.png`
- 용기 몸통은 y≈330~450 영역, 입구 중심은 x=240, y≈332 에 오도록 그려주세요.
- **밝은 회색/흰색 계열**로 그리세요. 선택한 색상이 곱하기(multiply)로 입혀집니다.

## flowers/ — 꽃·식물 (투명 PNG, 크기 자유)
- `tulip.png`, `rose.png`, `daisy.png`, `sunflower.png`, `babys_breath.png`, `leaf.png`, `cactus.png`
- 줄기 포함 전체 모습을 그리고, **줄기 아래쪽 중앙**이 이미지 하단 중앙에 오도록 해주세요.
- 비율은 유지되며 높이는 앱이 자동으로 맞춥니다.
